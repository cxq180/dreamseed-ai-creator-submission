# 1688 找货源 AI 助手

作者：cxq180

## 项目简介

这是一个面向跨境选品和货源检索场景的 AI 辅助作品，用于参加 DreamSeed 种梦计划 AI 创造者大赛。项目目标是把日常找货、翻译、关键词扩展和商品线索整理流程做成更轻量的 AI 工作流，帮助用户更快从需求描述定位到可采购、可比较、可继续跟进的货源线索。

## AI 相关能力

- 根据用户输入的商品需求，辅助生成更适合搜索的中文关键词、同义词和场景词。
- 辅助整理 1688 货源线索，包括品类、卖点、价格区间、供应商信息和后续跟进事项。
- 支持把中文商品信息翻译成面向跨境销售的英文标题、卖点和描述草稿。
- 通过 AI 辅助生成选品分析、商品对比和上架内容初稿。

## 适用场景

- 跨境电商卖家快速查找货源。
- 留存候选商品和供应商线索。
- 把零散商品信息整理成可复盘的选品记录。
- 将中文货源资料转成英文销售素材草稿。
